# Public-site quality checklist

1. Open https://mohamedtammam-geo.github.io/govision-earth/ in a private browser window.
2. Confirm satellite imagery displays without watermarks; switch to Streets.
3. Test three dates and all six radar views.
4. Activate Compare side by side; select Ascending on the left and Descending on the right; drag and zoom.
5. Confirm light/dark theme and map-label toggles, opacity and extent reset.
6. Switch F1, Precision, Recall and F2; switch the four temporal area series.
7. Download CSV and verify exported data.
8. Test at mobile width and confirm visible legend, credits, and map controls.
9. Read the Scientific Method page for the scope of the Sentinel-2 optical comparison.

If a basemap provider cannot be reached in a browser, switch to the other basemap. Basemap access depends on third-party services; NISAR thematic map files are bundled locally.

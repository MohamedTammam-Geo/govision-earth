## Citation guidance

For formal publication, cite the actual NISAR granule IDs, SAR processing method and specific Sentinel-2 product IDs archived in the original Stage 01/03 manifests. This lightweight web package does not reproduce original instrument granule metadata verbatim. Do not state that the NASA mission or challenge endorses this third-party software.
